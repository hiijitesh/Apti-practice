# Archived Scripts

These scripts were one-off extraction, migration, or early fix scripts used during development.
They are archived here for historical reference.

Active extraction, rebuild, and verification tooling is located directly in `scripts/`:
- `rebuild_verified_dixit.py`: Master rebuild script verifying Dixit Sir questions directly against PDF sheets.
- `verify_against_pdfs.py`: Automated audit validator checking questions and answer keys against source PDFs.
- `universal_pdf_question_extractor.py`: Spatial 2D bounding box PDF question extractor.
- `google_apps_script.js`: Google Sheets synchronization script.
